# Natural Earth (public domain)

`countries.bin` is converted from **Natural Earth 1:110m Cultural Vectors,
Admin 0 – Countries** (`ne_110m_admin_0_countries`), outer rings only,
coordinates rounded to 0.01°.

Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com.

Natural Earth's borders are its own de facto view; this private map draws
them only to show where money was spent.

Regenerate with `cargo run -p finance-core --example geo_assets` (see the
example's header for the inputs).
